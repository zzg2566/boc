# 青鉴实干｜青年政绩观 H5

中国银行益阳分行青年政绩观主题栏目，聚焦求真务实、金融为民、合规稳健与久久为功，呈现青年干部的岗位感悟与生活照。

在线访问：[https://zzg2566.github.io/boc/](https://zzg2566.github.io/boc/)

当前版本已录入 11 位已收到完整素材的青年干部。宋锦羽按要求不制作；刘娟待资料与照片补齐后，在 `app/profiles.ts` 中追加即可。

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
pnpm export:pages
```
